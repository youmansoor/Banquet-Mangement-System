# Scope

## In scope
- Features explicitly requested and approved by the project owner.
- Focused changes that follow the existing Laravel 12 application structure.
- Tests and documentation updates required by an approved feature.

## Out of scope
- Unrequested rewrites or broad refactors.
- Dependency upgrades without explicit approval.
- Production deployment or destructive database actions without explicit approval.
