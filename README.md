Banquet Management system
Multi tenant system with admin panel



Project Description
The Banquet Management System is a multi-tenant web based software designed for banquet halls, marriage halls, event venues and event management businesses in Pakistan.
The system will help banquet businesses manage their complete daily operations from a single platform. Each business will have its own separate account, dashboard, users, customers, bookings, venues, packages, invoices, payments and financial records. The system will ensure that each tenant can only access and manage its own business data.
The platform will have a Super Admin Panel for the system owner to manage all registered businesses, subscriptions, users, system settings and overall platform activity.
For each banquet business, the Tenant Panel will provide tools to manage customers, venues, event bookings, packages, menus, quotations, contracts, invoices, payments, expenses, vendors and reports.
The main purpose of the system is to replace manual registers, spreadsheets and disconnected processes with one centralized system. It will help banquet owners and managers keep better control over bookings, avoid double bookings, track customer payments, manage expenses and understand their overall business performance.
The system will be designed as a scalable SaaS platform so new banquet businesses can be added without affecting existing tenants. Each tenant can have its own business information, staff accounts, permissions, pricing, branding and operational settings.
The initial version will focus on the core banquet management operations, while additional features such as advanced accounting, inventory, WhatsApp integration, mobile applications and advanced analytics can be added in future phases.

Central platform management. Manage tenants, subscriptions, users, system settings, packages, reports, payments and overall platform activity. 

2-Tenant Management 
Create and manage banquet businesses. Each tenant gets its own isolated data, users, settings, branding and business configuration. 

3. Tenant Dashboard 
Dashboard for each banquet business showing bookings, events, revenue, pending payments, upcoming events and other important business information 

4. User & Role Management 
Manage tenant employees and assign permissions. Roles can include Owner, Manager, Accountant, Sales Staff, Receptionist and other custom roles. 

5. Customer Management 
Maintain customer profiles, contact details, CNIC information if required, event history, quotations, bookings, payments and communication records.

6. Venue / Hall Management 
Manage banquet halls, rooms or event spaces. Define capacity, facilities, pricing, availability and booking rules for each venue.

7. Event & Booking Management
Manage all customer event bookings through a calendar based booking system. The tenant can create and manage bookings for weddings, mehndi, baraat, walima, corporate events, birthdays and other functions.
The booking calendar will display all confirmed and scheduled events on their respective dates. Each booking will show basic information such as customer name, event type, venue and booking status.
When the user clicks on a specific date or booking in the calendar, a details modal will open showing complete booking information, including customer details, event date and time, venue, guest count, selected package, menu, payment status and other booking details.
The system will also check venue availability and help prevent double bookings for the same date and time.
